# Virtual Assistant Portfolio

This project is a React-based Single Page Application (SPA) built with Vite and Tailwind CSS. 

## Uploading Your Video

To see the background video working in your site:
1. Drag and drop your `.mp4` video file into the `public` folder inside the AI Studio file explorer.
2. Rename the file to **`background-video.mp4`**.
3. Re-build or preview your app to see the video playing in the background of the About section.

## GitHub Integration

### Step 1: Exporting to GitHub
1. In the top right corner of the AI Studio Builder UI, click on the **Settings** (gear) icon or the **Export** menu.
2. Select **Export to GitHub**.
3. Follow the authentication prompts to link your GitHub account and specify a repository name.
4. Your code will be pushed directly to a new GitHub repository.

### Step 2: Making Changes via GitHub
Once the project is hosted on your GitHub, you can:
- Clone it locally (`git clone <your-repo-url>`).
- Run `npm install` to download dependencies.
- Run `npm run dev` to start the local development server.
- Run `npm run build` to generate the production files in the `dist` folder.

## WordPress Integration

We've configured Vite to use relative paths (`base: './'`), so embedding this built React app into WordPress is much simpler.

### Option 1: WordPress Plugin (Easiest)
You can use a plugin like **ReactPress** to easily deploy this React app inside any WordPress page.
1. Build your app locally running `npm run build`. This generates a `dist` folder.
2. Install the [ReactPress plugin](https://wordpress.org/plugins/reactpress/) on your WordPress site.
3. Upload your `dist` folder to ReactPress through your WordPress Admin dashboard.
4. Assign the app to a specific page or slug in WordPress.

### Option 2: Upload via FTP / HTML page block
1. Build your app by running `npm run build`.
2. Access your WordPress hosting via FTP (or cPanel File Manager).
3. Create a folder in your WordPress file system (e.g., `wp-content/uploads/va-portfolio/`).
4. Upload all the contents inside the `dist` folder to this new directory.
5. You can now iframe this directory securely from any WordPress page:
   ```html
   <iframe src="https://yourwebsite.com/wp-content/uploads/va-portfolio/index.html" width="100%" height="900px" frameborder="0"></iframe>
   ```

### Option 3: Headless WordPress / Custom Theme integration
If you are building a custom WordPress theme, you can enqueue the exact built assets from the `dist/assets` folder using `wp_enqueue_script` and `wp_enqueue_style` in your theme's `functions.php`. Because JS and CSS generated by Vite are optimized and bundled, you just need to reference the `.js` and `.css` files produced in the build.
